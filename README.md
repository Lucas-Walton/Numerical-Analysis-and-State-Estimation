# Numerical Analysis and State Estimation Project

This project applies numerical methods and sensor filtering to real-world engineering problems, with a focus on state estimation for dynamic systems such as rockets and embedded platforms.

## Goals
- Implement core numerical methods (derivative approximations, Newton–Cotes formulas, Gaussian quadrature, stability analysis).
- Explore floating‑point behavior, machine epsilon, and error propagation.
- Develop a discrete-time Kalman filter to mitigate sensor noise and estimate system state.

## Current Status
- Studying numerical integration, derivative approximations, machine precision, and stability through coursework.
- Self-learning Kalman filtering and sensor fusion concepts.
- Drafting pseudocode and initial implementations for numerical methods and Kalman filtering.
- Planning embedded deployment on Raspberry Pi Pico and/or Arduino.

## Technologies
- C / Arduino
- Raspberry Pi Pico
- Python (for simulation and visualization)
- Numerical analysis and linear algebra

## Next Steps
- Build comfort with C/Arduino for embedded implementation.
- Simulate sensor data with realistic noise profiles.
- Implement and test a Kalman filter for state estimation.

## Why It Matters
State estimation is fundamental to avionics and Guidance, Navigation, and Control (GNC). Numerical analysis, filtering, and embedded systems form the mathematical and computational backbone of how rockets, drones, and autonomous systems understand their true position, velocity, and orientation despite noisy sensor data.
